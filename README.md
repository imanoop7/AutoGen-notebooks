# AutoGen-Notebooks
This repository contains various Jupyter notebooks demonstrating the use of the AutoGen library for different tasks. Below is a brief description of each notebook:

I am continuously exploring and will add more files as I progress.

- **1.ipynb**: Demonstrates the initialization of a ConversableAgent and setting up configurations for a debate between pizza and sushi.
- **basic_RAGAgent_with_autogen.ipynb**: Shows how to use the IPython display module and set up a LocalCommandLineCodeExecutor with the AutoGen library.
- **custom-agents-gemini.ipynb**: Contains code for comparing the year-to-date gain for META and TESLA stocks.
- **custom-agents.ipynb**: Contains code for plotting stock price changes for META and TESLA, saving the data to a CSV file, and generating a chart.
- **experiment.ipynb**: Sets up configurations for the llama3.2 model and initializes a UserProxyAgent.
- **memory_autogen.ipynb**: Demonstrates the use of the AutoGen library with chromadb and other libraries for memory components.
- **memory_component.ipynb**: Shows how to store and retrieve memory components using the AutoGen library.
- **ollama_and_lmstudio.ipynb**: Demonstrates the setup of different AssistantAgents with various configurations.
- **sequential_chat.ipynb**: Shows the setup for sequential chat tasks using the llama3.2 model.
- **with_agentops.ipynb**: Demonstrates the use of environment variables to set up AGENT_OPS_KEY and other configurations.
- **teacheable_agent.ipynb**: Contains configurations and code for a teachable agent.


More files will be added in the future as I continue to expand my knowledge and skills.
